## What is Anki?

[Anki](https://apps.ankiweb.net/) is a free, open-source flashcard application that uses spaced repetition to help reinforce information over time.

Instead of reviewing every card equally, Anki adjusts how frequently cards appear based on how well you remember them. Cards that are difficult are shown more often, while cards that are consistently answered correctly are reviewed less frequently.

## Importing and Using the Deck

To use this deck:

1. Install Anki from the official Anki website if it is not already installed.
2. Download the `.apkg` file from this folder.
3. Open Anki and select **File → Import**, or simply open the `.apkg` file directly.
4. Select the downloaded deck package and complete the import.
5. The deck should then appear in your Anki deck list and can be studied normally.
6. When reviewing cards, answer based on what you recall before revealing the back of the card, then rate your response using Anki's review buttons.
7. For best results, use the deck consistently rather than attempting to review the entire set at once.

The cards contain HTML formatting intended to make important concepts, distinctions, and terms easier to recognize during review. They should work with both desktop and mobile versions of Anki.
