# D831 Introduction to AI and Security

Self-study repository for WGU's D831 course.

## Repository purpose
This repo is organized to store reusable study artifacts for D831, including Anki flashcards.

## Study materials
- `anki/d831_flashcards.tsv` - tab-separated flashcards ready to import into Anki

## Importing into Anki
1. Open Anki and choose **Import File**.
2. Select `anki/d831_flashcards.tsv`.
3. Set field separator to **Tab**.
4. Map fields as:
   - Field 1: Front
   - Field 2: Back
   - Field 3: Tags

# Personal Opinion

My personal opinion of the course is that it was mediocre. It has mild disconnects in terminology, and terminology uses. The study questions are poorly worded and often disjointed in conjunction with what the textbook actually teaches. It looks like they pulled the course together from at least 3 different books (and probably several people/instructors) and it shows. I think WGU would have done better going with the new CompTIA AI Fundamentals certificate (not certification) for a basic AI course. CompTIA can be bad at times too, but they are also way more consistent. zyBooks cites several good sources for consolidated terminology (I placed several of the NIST and EU documents in the subfolder Helpful_Documents), but then fails to utilize them, or utilizes them inconsistently. This could have been a good course; but it was not. I'd rate the course and the course material as of September 2026 as D+.
